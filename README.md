# 🔥💧 冰火小冒险

一款**可爱画风的双人合作联机闯关游戏**(灵感来自经典游戏「森林冰火人」)。
两个人分别扮演 **小火 🔥** 和 **小水 💧**,互帮互助一路闯关:
踩按钮、开门、坐电梯、蹦床、躲岩浆水池毒刺,收集宝石走到各自的出口!

- ✅ **Windows 电脑**打开浏览器就能玩;**手机**也能玩(触屏摇杆)
- ✅ **联机对战无距离限制**(把服务器部署到公网,或同一 WiFi 局域网直连)
- ✅ **24 个手工设计的关卡**,难度循序渐进,每关都教一个新机关,绝不劝退
- ✅ **第 25 关起为无尽随机关卡**,永远有新关玩(同一关号所有玩家看到的地图完全相同)
- ✅ 零依赖:服务器只需 Node.js,**双击 `start.bat` 一键启动**,无需安装任何 npm 包
- ✅ 可爱画风:圆滚滚的小火小水、会眨眼的按钮、会开门的笑脸门、星星宝石、合成音效与背景音乐

---

## 一、快速开始(Windows)

1. 安装 Node.js(如果还没有):官网 <https://nodejs.org> 下载 **LTS 版本**,一路「下一步」即可。
2. **双击 `start.bat`** —— 它会自动打开浏览器进入游戏。
3. 选「🎮 单机双人闯关」或「📚 关卡选择」直接开始玩!

> 也可以手动运行:
> ```
> node server.js
> ```
> 然后浏览器打开 <http://localhost:3000>

## 二、手机怎么玩

**方式 A:同一 WiFi(家里/宿舍局域网)**
1. 电脑上启动服务器(双击 `start.bat`),命令行会显示一行:
   ```
   局域网访问: http://192.168.x.x:3000 (手机连同一 WiFi 即可)
   ```
2. 手机连**同一个 WiFi**,用浏览器打开这个地址即可。

**方式 B:全网联机(无距离限制,推荐)**
把本项目部署到免费的公网服务器(见下文第四节),之后把网址发给任何地方的
朋友,创建房间、分享 4 位房间号,天涯海角一起闯关!

## 三、联机玩法(怎么两个人一起玩)

1. 其中一人打开游戏 →「🌐 联机闯关」→「➕ 创建房间」→ 选一个关卡。
2. 页面显示 **4 位房间号**(点一下自动复制),把它发给朋友。
3. 朋友打开游戏 →「🌐 联机闯关」→ 输入房间号 →「🔑 加入」。
4. 人到齐后自动倒计时 3-2-1 开始!房主 = 🔥小火,加入者 = 💧小水。
5. 过关后任意一人点「下一关」,两人一起进入下一关。

> 断线了怎么办?15 秒内点「重新连接」可以回到原房间;
> 队友彻底掉线后,你会自动接管两个角色,关卡不受影响。

## 四、无距离限制:免费公网部署(约 5 分钟)

> 📖 **最详细的图文版请直接看本目录的 `部署指南-永久公网联机.md`**(含 GitHub 上传、
> Render 一键部署、常见问题),下面为简要版。

本项目**一个进程同时提供网页和联机服务**,部署到任何支持 Node.js 的平台即可。
下面任选一种:

### 方案 1:Render(免费,最简单)

1. 注册 <https://render.com>(可用 GitHub 账号)。
2. 把本项目上传到一个 GitHub 仓库(新建仓库 → 上传整个文件夹)。
3. Render 控制台 → **New → Web Service** → 选择该仓库。
4. 设置:
   - Build Command: `npm install`(或留空,本项目零依赖)
   - Start Command: `node server.js`
5. 点 **Create Web Service**,等待部署完成,得到一个
   `https://xxxx.onrender.com` 网址 —— 发给朋友就能联机!

> 免费版闲置一段时间会休眠,首次访问需要等 1 分钟左右唤醒,属正常现象。

### 方案 2:Railway / Fly.io 等

- Railway:新建项目 → Deploy from GitHub → 选仓库,启动命令 `node server.js`。
- Fly.io:`fly launch` 后把 `fly.toml` 里的端口改为环境变量 `PORT` 对应值。

### 方案 3:自己的云服务器(VPS/学生机)

```bash
# 上传本目录到服务器后:
node server.js
# 防火墙放行 3000 端口,即可用 http://服务器IP:3000 访问
# 建议用 nginx / caddy 反代并加 HTTPS
```

## 五、操作说明

| 平台 | 🔥 小火 | 💧 小水 |
| --- | --- | --- |
| 电脑键盘 | `WASD`(W 跳) | `方向键`(↑ 跳) |
| 手机(单机) | 左半边摇杆 + 跳跃按钮,点 🔄 切换控制谁 | 同左 |
| 手机(联机) | 你只控制自己的角色 | 同左 |

- `Esc` / `P` / 右上角 ⏸ 键:暂停。
- 单机模式下电脑可同时控制两人;手机上通过 🔄 按钮切换角色(站着的角色会
  继续帮你按住按钮,单人也能解开合作谜题)。

## 六、游戏机制(图例)

| 符号 | 含义 |
| --- | --- |
| 🔥 | 小火:怕 💧水池、☠毒池、尖刺;**不怕岩浆** |
| 💧 | 小水:怕 🌋岩浆、☠毒池、尖刺;**不怕水池** |
| ⭐ 宝石 | 捡得越多星星越多(全收集且零阵亡 = 3 星) |
| 🔘 按钮 `a/b/c/d` | 踩住开门;松开后门还会再开 1 秒多(一个人也能冲过去) |
| 🚪 门 `A/B/C/D` | 被对应按钮控制 |
| 🛗 电梯/移动桥 | 站上去会被带着走 |
| 🦘 蹦床 | 弹上高空拿宝石 |
| 🚪 X / Y | 小火 / 小水的出口,两个人都到就过关 |

## 七、关卡与难度

- 第 1~24 关:手工设计,每一关引入一个**新机关**,难度**平缓递增**:
  水池 → 岩浆 → 分路 → 按钮门 → 移动桥 → 电梯 → 双机关 → 毒池 → 尖刺 →
  蹦床 → 迷宫 → 立体路线 → 机关组合 → 长关 → 多楼层 → 分头行动 → 三机关 →
  空中浮岛 → 大综合 → 宝石收集 → 极速桥 → 终极考验 → 冠军之路。
- 第 25 关起:程序生成的**无尽关卡**(难度封顶,不会变态难),永远有新图。
- 关卡进度和星星会自动保存在本机浏览器里;关卡选择页可以重玩任何已解锁的关。

## 八、常见问题

- **端口被占用?** 换端口启动:`set PORT=8080 && node server.js`(PowerShell 用 `$env:PORT=8080`)。
- **双击 start.bat 一闪而过?** 说明没装 Node.js,先安装再重试。
- **手机打不开局域网地址?** 确认手机和电脑在同一 WiFi;若电脑开了防火墙,放行 Node.js。
- **想直接用浏览器双击 index.html 玩?** 单机模式可以(选关/进度都在),
  但联机必须通过服务器地址访问页面。
- **如何修改/新增关卡?** 编辑 `public/js/levels.js`,按文件顶部图例加关卡即可,
  改完运行 `node tools/validate.js` 会自动检查关卡是否可通关。
